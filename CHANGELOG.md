# Changelog

## v0.1.0

First release.

- Banner with the EC fan mode (Performance, Balanced, Silent) after Fn+K, removed from the notification list once shown.
- `status` prints the current mode and fan readings.
- `record` and `diff` to map the EC on other models.
- Optional workarounds for the `bitland_mifs_wmi` platform profile that BIOS `RMAAD5B0P1010` rejects.
